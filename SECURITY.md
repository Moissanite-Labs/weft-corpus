# Security policy

This repository holds archived documents and an integrity check. To report a vulnerability in any Weft repository,
follow the [ML Weft security policy](https://github.com/Moissanite-Labs/weft/blob/main/SECURITY.md): use GitHub's
private vulnerability reporting, or email security@w3ft.org.

Code listings in the corpus are historical and not maintained. Problems in them are not vulnerabilities in Weft, and
can be raised as ordinary issues in Moissanite-Labs/weft.
